1. **Initialize**:

   - Create a priority queue to store nodes and their distances.

2. **Process Nodes**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is connected to it.
   - If the new distance is less than the current known distance, update the distance and add the neighbor to the priority queue.

3. **Termination**:
   - Continue this process until the priority queue is empty.

4. **Extract Path**:
   - Once the shortest path is found, trace back from the destination (Nell) to the starting node (Dove) to get the path.
