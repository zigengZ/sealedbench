### Step 1: Understand the connections

We need to find a path from **Cleo** to **Kai**.

Start with Cleo:
- Cleo is connected only to **Tess** (weight 5)

From Tess:
- Tess is connected to:
  - Cleo (5)
  - Drew (3)
  - Kai (2)

So from Tess, we can go to **Drew** (3) or **Kai** (2)

So one direct path:  
**Cleo → Tess → Kai**  
Weight = 5 + 2 = **7**
