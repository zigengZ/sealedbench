To find the shortest path between Cedar and Xen, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to the starting node (Cedar) as 0.
   - Set the distance to all other nodes as infinity.
   - Create a priority queue to store nodes with their current shortest distance.

2. **Process Nodes**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is closer.
   - Update the distance and add the neighbor to the priority queue if the new distance is smaller.

3. **Termination**:
   - Continue until the priority queue is empty.
   - The distance to the target node (Xe) will be the shortest path weight.

Let's implement this in Python:

```python
import heapq

# Define the graph
graph = {
    'Cedar': 0,
    'Drew': 7,
    'Hart': 5,
    'Nell': 2,
    'Oak': 5,
    'Poe': 7,
    'Quill': 3,
    'Uri': 9,
    'Xen': 1
}

# Initialize distances
distances = {node: float('infinity') for node in graph}
distances['Cedar'] = 0

# Priority queue to store nodes with their current shortest distance
priority_queue = [(0, 'Cedar')]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances for neighbors
    for neighbor, weight in graph.items():
        if distances[neighbor] + weight < current_distance:
            distances[neighbor] = current_distance + weight
            heapq.heappush(priority_queue, (distances[neighbor] + weight, neighbor))

# Extract the shortest path weight
shortest_path_weight = distances['Xe']

print(shortest_path_weight)
```
