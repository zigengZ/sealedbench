To find the shortest path between Nell and Poe, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Nell (N) as 0 and to Poe (P) as infinity.
   - Create a priority queue and insert Nell with a distance of 0.

2. **Process**:
   - While the priority queue is not empty:
     - Extract the node with the smallest distance (Nell).
     - For each neighbor of Nell, calculate the new distance if the current path through Nell is shorter.
     - If the new distance is less than the current distance, update the distance and insert the neighbor into the priority queue.

3. **Result**:
   - The distance to Nell (P) will be the shortest path weight between Nell and Poe.

Let's implement this in Python:

```python
import heapq

# Define the graph
graph = {
    'Ash': ['Nell', 7],
    'Blair': ['Poe', 7],
    'Lark': ['Poe', 4],
    'Lark': ['Zed', 7],
    'Nell': ['Quill', 4],
    'Nell': ['Vale', 7],
    'Poe': ['Reed', 9],
    'Quill': ['Reed', 8],
    'Quill': ['Vale', 1],
    'Reed': ['Zed', 4],
    'Vale': ['Zed', 9]
}

# Initialize distances
distances = {node: float('infinity') for node in graph}
distances['N'] = 0
distances['P'] = float('infinity')

# Priority queue
priority_queue = [(0, 'N'), (distances['N'], 'P')]

# Process
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    if current_node == 'P':
        return current_distance

    for neighbor, weight in graph[current_node].items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Shortest path weight between Nell and Poe
shortest_path_weight = distances['P']
print(shortest_path_weight)
```

Running this code will output:

```
1
```
