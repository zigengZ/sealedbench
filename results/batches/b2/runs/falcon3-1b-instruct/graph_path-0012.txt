To find the shortest path between Amber and Moss, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Amber as 0 and to Moss as infinity.
   - Create a priority queue and insert all nodes with their initial distances.

2. **Process**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is connected to the neighbor.
   - If the new distance is less than the current known distance, update the distance and insert the neighbor into the priority queue.

3. **Termination**:
   - Continue this process until the priority queue is empty.
   - The distance to Moss will be the shortest path weight.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ['Amber', 'Drew', 'Eden', 'Indigo', 'Kai', 'Moss', 'Sage', 'Uri']
distances = {node: float('infinity') for node in nodes}

# Distances from Amber to each node
amber_to_nodes = {node: distances[node] for node in nodes}

# Distances from each node to Moss
for amber in nodes:
    distances[amber] = distances[amber] + distances[amber_to_nodes[amber]]

# Priority queue implementation
priority_queue = [(0, amber)]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    if current_node == moss:
        shortest_path_weight = current_distance
        break
    for neighbor, weight in amber_to_nodes.items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Shortest path weight between Amber and Moss
shortest_path_weight = distances[moss]
print(shortest_path_weight)
```
