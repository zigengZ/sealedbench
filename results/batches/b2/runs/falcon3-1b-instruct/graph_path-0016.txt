To find the shortest path between Cedar and Xen, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to the starting node (Cedar) as 0 and all other nodes as infinity.
   - Create a priority queue to store nodes and their distances.

2. **Process Nodes**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is the intermediate step.
   - Update the distance and add the neighbor to the priority queue if the new distance is smaller.

3. **Termination**:
   - Continue until the priority queue is empty.

Let's implement this in Python:

```python
import heapq

# Define the graph
graph = {
    'Ash': ['Cleo', 'Kay'],
    'Bay': ['Cleo', 'Quill'],
    'Cedar': ['Quill', 'Xeno'],
    'Cleo': ['Fern', 'York'],
    'Fern': ['York'],
    'Kai': ['Xeno'],
    'Quill': ['Xeno'],
    'Xen': ['York'],
    'York': ['Quill', 'Xeno']
}

# Initialize distances
distances = {node: float('infinity') for node in graph}
distances['Cedar'] = 0

# Priority queue to store nodes and their distances
priority_queue = [(0, 'Cedar')]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances for neighbors
    for neighbor, weight in graph[current_node].items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Calculate the total weight of the shortest path between Cedar and Xen
total_weight = distances['Cedar']
print(total_weight)
```
