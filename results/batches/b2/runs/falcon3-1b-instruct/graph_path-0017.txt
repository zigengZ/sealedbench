To find the shortest path between Bay and Glen, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to the starting node (Bay) as 0 and all other nodes as infinity.
   - Create a priority queue to store nodes and their distances.

2. **Process Nodes**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is the intermediate node.
   - Update the distance and add the neighbor to the priority queue if the new distance is smaller.

3. **Termination**:
   - Continue until the priority queue is empty.

4. **Result**:
   - The distance from Bay to Glen will be the smallest value in the priority queue.

Let's implement this in Python:

```python
import heapq

# Define the graph
graph = {
    'Bay': 8,
    'Dove': 2,
    'Drew': 4,
    'Eden': 4,
    'Fern': 4,
    'Glen': 5,
    'Hart': 5,
    'Zed': 8,
    'Zed': 6
}

# Initialize distances
distances = {node: float('inf') for node in graph}
distances['Bay'] = 0

# Priority queue to store nodes and their distances
priority_queue = [(0, 'Bay')]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances for neighbors
    for neighbor, weight in graph.items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Distance from Bay to Glen
distance_Bay_to_Glen = distances['Glen']

print(f"The total weight of the shortest path between Bay and Glen is {distance_Bay_to_Glen}")
```
