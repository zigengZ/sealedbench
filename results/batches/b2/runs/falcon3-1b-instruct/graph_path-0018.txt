To find the shortest path between Blair and York, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Blair as 0 and to York as ∞.
   - Create a priority queue and insert all nodes with their initial distances.

2. **Process**:
   - While the priority queue is not empty:
     - Extract the node with the smallest distance.
     - For each neighbor of the current node:
       - Calculate the new distance through the current node.
       - If this new distance is less than the current known distance, update the distance and insert the neighbor into the priority queue.

3. **Result**:
   - The distance from Blair to York will be the smallest value in the priority queue.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ['Blair', 'Cedar', 'Dove', 'Fern', 'Glen', 'Lark', 'Moss', 'Sage', 'York']
distances = {node: float('inf') for node in nodes}

# Edges with weights
edges = {
    'Blair': ['Fern', 'Lark'], dist=9, weight=6,
    'Blair': ['Lark', 'Dove'], dist=6, weight=4,
    'Cedar': ['Lark', 'Dove'], dist=4, weight=7,
    'Dove': ['Fern', 'Sage'], dist=5, weight=5,
    'Fern': ['Lark', 'Moss'], dist=2, weight=2,
    'Fern': ['Moss', 'Lark'], dist=2, weight=2,
    'Glen': ['Lark', 'Moss'], dist=2, weight=5,
    'Lark': ['Moss', 'Sage'], dist=1, weight=1,
    'Moss': ['Sage', 'York'], dist=5, weight=1
}

# Priority queue to store nodes with their distances
priority_queue = [(0, {'Blair': 0, 'York': ∞})]

# Process the priority queue
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    if current_node == 'York':
        return current_distance

# Update distances for neighbors
for neighbor, (neighbor_distance, neighbor_edge) in edges.items():
    if neighbor_node == current_node:
        new_distance = current_distance + neighbor_edge.weight
        if new_distance < current_distance:
            heapq.heappush(priority_queue, (new_distance, {'Blair': current_distance, 'York': new_distance}))

print(priority_queue[0]['Blair']['York'])
```
