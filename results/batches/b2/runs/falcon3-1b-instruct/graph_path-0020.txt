To find the shortest path between Moss and Xen, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Moss as 0 and to Xen as infinity.
   - Create a priority queue and insert Moss with a distance of 0.

2. **Process**:
   - While the priority queue is not empty:
     - Extract the node with the smallest distance (Moss).
     - For each neighbor of Moss, calculate the new distance if the current path through Moss is shorter.
     - If the new distance is less than the current distance, update the distance and insert the neighbor into the priority queue.

3. **Result**:
   - The distance to Moss will be the shortest path weight between Moss and Xen.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ["Cleo", "Drew", "Fern", "Lark", "Moss", "Nell", "West", "Xen"]
distances = {node: float('inf') for node in nodes}

# Edges with weights
edges = {
    "Cleo Moss": 9,
    "Cleo Nell": 8,
    "Cleo Xen": 2,
    "Drew Fern": 1,
    "Drew West": 6,
    "Fern Moss": 3,
    "Fern Xen": 5,
    "Lark Moss": 3,
    "Lark Nell": 5,
    "Lark Xen": 2,
    "Nell York": 1,
    "West York": 3
}

# Priority queue to store nodes with their distances
priority_queue = [(0, "Moss", nodes[0])]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    if current_node == "Moss":
        continue  # Skip Moss

    for neighbor, weight in edges[current_node]:
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Distance to Moss
shortest_path_weight = distances["Moss"]

print(shortest_path_weight)
```

10
