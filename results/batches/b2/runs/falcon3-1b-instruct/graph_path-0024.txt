To find the shortest path between Tess and West, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Tess as 0 and to West as infinity.
   - Create a priority queue and insert all nodes with their initial distances.

2. **Relaxation**:
   - While the priority queue is not empty:
     - Extract the node with the smallest distance.
     - For each neighbor of the current node:
       - Calculate the new distance through the current node.
       - If the new distance is less than the current known distance, update the distance.
       - If the new distance is equal to the current known distance, mark the neighbor as visited.

3. **Termination**:
   - The algorithm terminates when the priority queue is empty, indicating that the shortest path has been found.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ['Bay', 'Cleo', 'Kai', 'Moss', 'Nell', 'Poe', 'Tess', 'West', 'Zed']
distances = {node: float('inf') for node in nodes}

# Distances from Tess to each node
distances['Tess'] = 0

# Priority queue for Dijkstra's algorithm
priority_queue = [(0, Tess)]

# Dijkstra's algorithm
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances for neighbors
    for neighbor, weight in nodes[current_node].items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))
    
# Shortest path weight between Tess and West
shortest_path_weight = distances['West']

print(shortest_path_weight)
```
