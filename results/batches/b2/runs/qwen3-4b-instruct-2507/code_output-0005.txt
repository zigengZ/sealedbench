```python
count = 0
for i in range(5):
    for j in range(4):
        if (i + j) % 4 == 0:
            count = count + i + 1
        else:
            count = count + j + 1
print(count)
```

- Inner loop: `j` goes from 0 to 3 (inclusive), so `j = 0, 1, 2, 3`
