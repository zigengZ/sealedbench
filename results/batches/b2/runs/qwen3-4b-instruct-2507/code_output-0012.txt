Let's analyze the given Python 3 program step by step:

```python
total = 0
for value in range(9):
    if value == 0:
        total = total + 0
    else:
        total = total + value
print(total)
```

### Step 1: Understand the loop
- `range(9)` generates numbers from 0 to 8 (inclusive).
- So, the loop will iterate over: `value = 0, 1, 2, 3, 4, 5, 6, 7, 8`

### Step 2: Trace the loop
- `total` starts at 0.

#### Iteration 1: value = 0
- `if value == 0`: True
- `total = total + 0` → `total = 0 + 0 = 0`

#### Iteration 2: value = 1
- `value != 0`, so go to `else`
- `total = total + value` → `total = 0 + 1 = 1`

#### Iteration 3: value = 2
- `total = 1 + 2 = 3`

#### Iteration 4: value = 3
- `total = 3 + 3 = 6`

#### Iteration 5: value = 4
- `total = 6 + 4 = 10`

#### Iteration 6: value = 5
- `total = 10 + 5 = 15`

#### Iteration 7: value = 6
- `total = 15 + 6 = 21`

#### Iteration 8: value = 7
- `total = 21 + 7 = 28`

#### Iteration 9: value = 8
- `total = 28 + 8 = 36`

### Final value of `total` is 36.

### Output:
The program prints `total`, which is 36.
