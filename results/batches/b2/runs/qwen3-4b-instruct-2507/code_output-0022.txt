```python
total = 0
for value in range(11):
    if value == 4:
        total = total + 0
    else:
        total = total + value
print(total)
```

- The loop iterates over each value in that range.
- For each value:
  - If `value == 4`, we add 0 to `total`.
  - Otherwise, we add the value itself to `total`.
