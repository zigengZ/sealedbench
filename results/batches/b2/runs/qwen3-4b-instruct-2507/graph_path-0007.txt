We are given an undirected weighted graph with nodes:  
**Blair, Drew, Indigo, Kai, Moss, Oak, West**

Edges and their weights:
- Blair – Moss: 2  
- Drew – Moss: 8  
- Drew – Oak: 4  
- Drew – West: 5  
- Indigo – Kai: 7  
- Indigo – Moss: 6  
- Indigo – West: 2  
- Kai – Moss: 3  
- Kai – Oak: 3  
- Oak – West: 8  

We are to find the **shortest path from Blair to Oak** in terms of total weight.

---

### Step 1: Understand the connections

We need to find the shortest path from **Blair** to **Oak**.

Blair is only directly connected to **Moss** (weight 2).  
So any path from Blair must go through Moss.

So we can think of the path as:
**Blair → Moss → ??? → Oak**

We now look for the shortest path from Moss to Oak, and add the 2 from Blair to Moss.

So we need to compute the shortest path from **Moss to Oak**, then add 2.

---

### Step 2: Find shortest path from Moss to Oak

From Moss, possible neighbors:
- Blair (2) — not useful for going to Oak
- Drew (8)
- Indigo (6)
- Kai (3)

So from Moss, we can go to:
- Drew (8)
- Indigo (6)
- Kai (3)

From each of these, we can explore paths to Oak.

Let’s explore all possible paths from Moss to Oak.

---

#### Option 1: Moss → Kai → Oak  
- Moss to Kai: 3  
- Kai to Oak: 3  
→ Total: 3 + 3 = **6**

#### Option 2: Moss → Indigo → West → Oak  
- Moss → Indigo: 6  
- Indigo → West: 2  
- West → Oak: 8  
→ Total: 6 + 2 + 8 = **16**

#### Option 3: Moss → Indigo → Moss → ??? → Oak — no improvement

#### Option 4: Moss → Drew → Oak  
- Moss → Drew: 8  
- Drew → Oak: 4  
→ Total: 8 + 4 = **12**

#### Option 5: Moss → Kai → Moss → ??? — loops, not helpful

#### Option 6: Moss → Indigo → Kai → Oak  
- Moss → Indigo: 6  
- Indigo → Kai: 7  
- Kai → Oak: 3  
→ 6 + 7 + 3 = **16**

So best path from Moss to Oak is **Moss → Kai → Oak** with weight **6**

---

### Step 3: Add Blair to Moss

Blair → Moss: 2  
Moss → Kai → Oak: 6  
Total: 2 + 6 = **8**

---

### Final Answer:
#### 8 [end of text]
