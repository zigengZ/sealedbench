We are given an undirected weighted graph with nodes:

**Nodes**: Blair, Cedar, Dove, Fern, Glen, Lark, Moss, Sage, York  
**Edges and weights**:

- Blair — Fern: 9  
- Blair — Lark: 6  
- Cedar — Lark: 4  
- Dove — Fern: 7  
- Dove — Sage: 5  
- Fern — Lark: 1  
- Fern — Moss: 2  
- Glen — Lark: 2  
- Glen — Moss: 5  
- Glen — Sage: 1  
- Glen — York: 3  

We are to find the **shortest path from Blair to York** in terms of total weight.

---

### Step 1: Understand the structure

We can model this as a graph and apply a shortest path algorithm (like Dijkstra’s), since all weights are positive.

We start at **Blair**, and want to reach **York**.

Let’s explore possible paths from Blair to York.

---

### Step 2: List all neighbors of Blair

- Blair → Fern (9)
- Blair → Lark (6)

So from Blair, we can go directly to:
- Fern (cost 9)
- Lark (cost 6)

Now, from Lark, we can go to:
- Cedar (4)
- Fern (1)
- Glen (2)

From Fern:
- Dove (7)
- Moss (2)
- Lark (1)

From Glen:
- Lark (2)
- Moss (5)
- Sage (1)
- York (3)

From Sage:
- Dove (5)
- Glen (1)

From Dove:
- Fern (7)
- Sage (5)

From Moss:
- Fern (2)
- Glen (5)

From Cedar: only connected to Lark (4)

---

### Step 3: Try possible paths from Blair to York

#### Path 1: Blair → Lark → Glen → York  
- Blair → Lark: 6  
- Lark → Glen: 2  
- Glen → York: 3  
→ Total: 6 + 2 + 3 = **11**

#### Path 2: Blair → Lark → Fern → Moss → Glen → York  
- Blair → Lark: 6  
- Lark → Fern: 1  
- Fern → Moss: 2  
- Moss → Glen: 5  
- Glen → York: 3  
→ Total: 6 + 1 + 2 + 5 + 3 = **17** → worse

#### Path 3: Blair → Lark → Fern → Dove → Sage → Glen → York  
- Blair → Lark: 6  
- Lark → Fern: 1  
- Fern → Dove: 7  
- Dove → Sage: 5  
- Sage → Glen: 1  
- Glen → York: 3  
→ Total: 6+1+7+5+1+3 = **23** → worse

#### Path 4: Blair → Fern → Moss → Glen → York  
- Blair → Fern: 9  
- Fern → Moss: 2  
- Moss → Glen: 5  
- Glen → York: 3  
→ Total: 9+2+5+3 = **19** → worse than 11

#### Path 5: Blair → Fern → Lark → Glen → York  
- Blair → Fern: 9  
- Fern → Lark: 1  
- Lark → Glen: 2  
- Glen → York: 3  
→ Total: 9+1+2+3 = **15** → worse
