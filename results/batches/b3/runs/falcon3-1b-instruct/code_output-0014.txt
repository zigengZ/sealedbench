The exact standard output of the given Python 3 program is `20`.

```python
values = [15, 7, 0, 16, 7]
total = 2
for value in values:
    if value < 14:
        total = total + value
    else:
        total = total + 1
print(total)
```

Explanation:

1. The program initializes a list `values` with the elements `[15, 7, 0, 16, 7]`.
2. It also initializes a variable `total` with the value `2`.
3. The `for` loop iterates over each element `value` in the `values` list.
4. Inside the loop, it checks if the current `value` is less than `14`.
5. If `value` is less than `14`, it adds `value` to `total`.
6. If `value` is not less than `14`, it adds `1` to `total`.
7. After the loop completes, the final value of `total` is printed.

The output is `20`, which is the sum of all elements in the `values` list that are less than `14`. [end of text]
