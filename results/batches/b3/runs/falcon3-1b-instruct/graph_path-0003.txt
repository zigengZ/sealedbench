To find the shortest path between Indigo and Oak, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Indigo as 0 and to Oak as infinity.
   - Create a priority queue and insert Indigo with a distance of 0.

2. **Process**:
   - While the priority queue is not empty:
     - Extract the node with the smallest distance.
     - For each neighbor of the current node:
       - Calculate the new distance through the current node.
       - If this new distance is less than the current known distance to the neighbor, update the distance and insert the neighbor into the priority queue.

3. **Result**:
   - The distance to Oak will be the smallest among all distances from Indigo.

Let's implement this in Python:

```python
import heapq

# Graph representation
graph = {
    'Bay': ['Nell', 4],
    'Fern': ['Indigo', 4],
    'Glen': ['Indigo', 3],
    'Indigo': ['Nell', 6],
    'Moss': ['Reed', 7],
    'Nell': ['West', 1],
    'Oak': ['West', 1],
    'Reed': ['West', 2],
    'West': ['Oak', 1]
}

# Initialize distances
distances = {node: float('inf') for node in graph}
distances['Indigo'] = 0
distances['Oak'] = float('inf')

# Priority queue to store nodes with their distances
priority_queue = [(0, 'Indigo')]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    if current_node == 'Oak':
        return current_distance

    for neighbor, weight in graph[current_node].items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Total weight of the shortest path between Indigo and Oak
print(distances['Oak'])
```
