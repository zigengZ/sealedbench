To find the shortest path between Ash and Drew, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Ash as 0 and to Drew as infinity.
   - Create a priority queue and insert all nodes with their initial distances.

2. **Process**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is connected to the neighbor.
   - If the new distance is less than the current known distance, update the distance and insert the neighbor into the priority queue.

3. **Result**:
   - After processing all nodes, the distance to Ash will be the minimum distance to Ash from the priority queue.
   - The distance to Drew will be the minimum distance to Drew from the priority queue.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ['Amber', 'Ash', 'Dove', 'Drew', 'Eden', 'Nell', 'Quill', 'Uri', 'York']
distances = {node: float('inf') for node in nodes}

# Edges with weights
edges = {
    'Amber Dove': 3,
    'Amber Nell': 2,
    'Amber Quill': 6,
    'Ash Nell': 7,
    'Ash Quill': 2,
    'Dove Uri': 4,
    'Dove York': 9,
    'Drew Nell': 1,
    'Drew York': 3
}

# Priority queue to store nodes with their distances
priority_queue = [(0, nodes)]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    if current_distance > distances[current_node]:
        continue

    # Update distances for neighbors
    for neighbor, weight in edges[current_node]:
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Distance to Ash
distance_to_ash = distances['Ash']

# Distance to Drew
distance_to_drew = distances['Drew']

print(f"Distance from Ash to Drew: {distance_to_drew}")
```
