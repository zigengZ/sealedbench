To find the shortest path between Uri and Zed in the given undirected weighted graph, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to the starting node (Dove) as 0.
   - Set the distance to all other nodes as infinity.
   - Create a priority queue to store nodes and their distances.

2. **Process Nodes**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node:
     - Calculate the tentative distance through the current node.
     - If this distance is less than the current known distance to the neighbor, update the distance.
     - Add the neighbor to the priority queue with the updated distance.

3. **Termination**:
   - Continue until the priority queue is empty.
   - The distance to the target node (Zed) will be the minimum distance found.

Let's implement this in Python:

```python
import heapq

# Define the graph
graph = {
    'Dove': {'Moss': 5, 'Uri': 5},
    'Dove': {'Uri': 5, 'Zed': 1},
    'Dove': {'Moss': 6, 'Uri': 2},
    'Drew': {'Moss': 6, 'Uri': 2},
    'Drew': {'Uri': 2, 'Vale': 2},
    'Vale': {'Zed': 2, 'Zed': 0}
}

# Initialize distances
distances = {node: float('infinity') for node in graph}
distances['Dove'] = 0

# Priority queue to store nodes and their distances
priority_queue = [(0, 'Dove', distances['Dove']])

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances to neighbors
    for neighbor, weight in graph[current_node].items():
        tentative_distance = current_distance + weight
        if tentative_distance < distances[neighbor]:
            distances[neighbor] = tentative_distance
            heapq.heappush(priority_queue, (tentative_distance, neighbor))

# Distance to Zed
distance_to_zed = distances['Zed']

print(distance_to_zed)
```
