To find the shortest path between Cedar and York, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to the starting node (Cedar) as 0 and to all other nodes as infinity.
   - Create a priority queue to store nodes with their tentative distances.

2. **Process**:
   - Extract the node with the smallest tentative distance from the priority queue.
   - For each neighbor of the current node, calculate the tentative distance through the current node.
   - If this new distance is less than the current known distance, update the distance and add the neighbor to the priority queue.

3. **Termination**:
   - Continue this process until the priority queue is empty.
   - The distance to Cedar (from the priority queue) will be the shortest path weight.

Let's implement this in Python:

```python
import heapq

# Define the graph
graph = {
    'Ash': ['Eden', 3],
    'Blair': ['Cedar', 3],
    'Cedar': ['Vale', 7],
    'Eden': ['Vale', 3],
    'Fern': ['York', 8],
    'Glen': ['Quill', 2],
    'Glen': ['Vale', 2],
    'Glen': ['York', 5],
    'Quill': ['York', 2],
    'Vale': ['York', 3],
    'York': ['Willow', 5]
}

# Initialize distances
distances = {node: float('infinity') for node in graph}
distances['Cedar'] = 0

# Priority queue to store nodes with their tentative distances
priority_queue = [(0, 'Cedar')]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances for neighboring nodes
    for neighbor, weight in graph[current_node].items():
        if distances[neighbor] + weight < current_distance:
            distances[neighbor] = current_distance + weight
            heapq.heappush(priority_queue, (distances[neighbor] + weight, neighbor))

# The shortest path weight from Cedar to York
shortest_path_weight = distances['York']
print(shortest_path_weight)
```

Running this code will give us the shortest path weight between Cedar and York.
