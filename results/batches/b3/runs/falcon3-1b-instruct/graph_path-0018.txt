To find the shortest path between Bay and Kai, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to the starting node (Ash) as 0 and to all other nodes as infinity.
   - Create a priority queue to store nodes and their distances.

2. **Process**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is connected to the neighbor.
   - Update the distance and add the neighbor to the priority queue if the new distance is smaller.

3. **Termination**:
   - Continue this process until the priority queue is empty.

Let's implement this in Python:

```python
import heapq

# Define the graph
graph = {
    'Ash': [8, 'Bay'],
    'Bay': [8, 'Tess'],
    'Cleo': ['Kai', 'Tess'],
    'Jules': ['Tess', 'Xen'],
    'Kai': ['Oak', 'Sage'],
    'Oak': ['Sage', 'West'],
    'Sage': ['West', 'Xen'],
    'Tess': ['West', 'West'],
    'West': ['Xen', 'West'],
    'Xen': ['West', 'West']
}

# Initialize distances
distances = {node: float('infinity') for node in graph}
distances['Ash'] = 0

# Priority queue to store nodes and their distances
priority_queue = [(0, 'Ash', distances['Ash'])]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # If current node is Kai
    if current_node == 'Kai':
        return current_distance
    
    # Update distances for neighbors
    for neighbor, weight in graph[current_node].items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Total weight of the shortest path between Bay and Kai
print(priority_queue[0][1])
```

Running this code will give us the total weight of the shortest path between Bay and Kai.
