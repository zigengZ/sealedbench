To find the shortest path between Fern and Glen, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Fern as 0 and to Glen as infinity.
   - Create a priority queue and insert all nodes with their initial distances.

2. **Relaxation**:
   - While the priority queue is not empty:
     - Extract the node with the smallest distance.
     - For each neighbor of the current node:
       - Calculate the new distance through the current node.
       - If the new distance is less than the current known distance, update the distance.
       - Insert the neighbor into the priority queue with the updated distance.

3. **Result**:
   - The distance from Fern to Glen will be the smallest distance found during the relaxation process.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ['Bay', 'Fern', 'Glen', 'Hart', 'Moss', 'Poe', 'Sage', 'Xen']
distances = {node: float('infinity') for node in nodes}

# Distances from Fern to each node
distances['Fern'] = 0

# Priority queue for relaxation
priority_queue = [(0, Fern)]

# Relax all nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances for neighbors
    for neighbor, weight in nodes[current_node].items():
        if distances[neighbor] + weight < current_distance:
            distances[neighbor] = current_distance + weight
            heapq.heappush(priority_queue, (distances[neighbor] + weight, neighbor))

# Distance from Fern to Glen
distance = distances['Fern']
print(distance)
```

Running this code will give us the shortest path distance from Fern to Glen.
