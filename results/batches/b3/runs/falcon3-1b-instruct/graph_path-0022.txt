To find the shortest path between Cleo and Dove, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to Cleo as 0 and to Dove as infinity.
   - Create a priority queue and insert all nodes with their initial distances.

2. **Process**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the new distance if the current node is the intermediate step.
   - If the new distance is less than the current known distance, update the distance and insert the neighbor into the priority queue.

3. **Termination**:
   - Continue this process until the priority queue is empty.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ["Cleo", "Dove", "Fern", "Hart", "Lark", "Nell", "Poe", "Quill"]
weights = {
    "Cleo": 9,
    "Cleo": 5,
    "Dove": 9,
    "Fern": 8,
    "Fern": 8,
    "Hart": 4,
    "Hart": 9,
    "Lark": 9,
    "Lark": 9
}

# Priority queue implementation
def priority_queue(weights, nodes):
    pq = []
    for node in nodes:
        pq.append((weights[node], node))
    return pq

# Dijkstra's algorithm implementation
def dijkstra(weights, nodes):
    pq = priority_queue(weights, nodes)
    distances = {node: float('infinity') for node in nodes}
    distances[nodes[0]] = 0

    while pq:
        current_distance, current_node = heapq.heappop(pq)

        if current_distance > distances[current_node]:
            continue

        for neighbor, weight in weights[current_node].items():
            new_distance = distances[current_node] + weight

            if new_distance < distances[neighbor]:
                distances[neighbor] = new_distance
                heapq.heappush(pq, (new_distance, neighbor))

    return distances

# Calculate the shortest path weight between Cleo and Dove
cleo_dove = dijkstra(weights, ["Cleo", "Dove"])
print(cleo_dove)
```
