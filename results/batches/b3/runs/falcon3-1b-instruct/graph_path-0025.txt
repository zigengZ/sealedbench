To find the shortest path between Hart and Moss in the given undirected weighted graph, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize Distances:**
   - Set the distance to Hart as 0 (since it's directly connected to Hart with an edge of weight 4).
   - Set the distance to Moss as infinity (since it's initially unknown).

2. **Distribute Distances:**
   - Start from Hart.
   - Update the distance to each neighbor (Blair, Jules, Kai, and Poe) based on the current shortest known distance.

3. **Repeat Until All Distances Are Known:**
   - Continue updating distances to all neighbors until all distances are known.

4. **Calculate the Total Weight:**
   - Once all distances are finalized, the total weight of the shortest path from Hart to Moss is the sum of the weights of the edges on the path.

Let's implement this in Python using the `networkx` library:

```python
import networkx as nx

# Define the graph
graph = nx.Graph()

# Add nodes and edges
graph.add_node('Blair')
graph.add_node('Hart')
graph.add_node('Jules')
graph.add_node('Kai')
graph.add_node('Moss')
graph.add_node('Oak')
graph.add_node('Poe')
graph.add_node('Xen')

# Add weights to the edges
graph.add_edge('Blair', 'Hart', weight=4)
graph.add_edge('Blair', 'Jules', weight=5)
graph.add_edge('Blair', 'Kai', weight=1)
graph.add_edge('Blair', 'Xen', weight=2)
graph.add_edge('Hart', 'Oak', weight=4)
graph.add_edge('Hart', 'Poe', weight=1)
graph.add_edge('Jules', 'Oak', weight=8)
graph.add_edge('Kai', 'Poe', weight=1)
graph.add_edge('Moss', 'Oak', weight=8)

# Run Dijkstra's algorithm to find the shortest path
shortest_path = nx.dijkstra_path(graph, 'Hart', 'Moss')

# Calculate the total weight of the shortest path
total_weight = sum(graph.edges[u][v]['weight'] for u, v in shortest_path)

print(total_weight)
```
