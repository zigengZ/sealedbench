To find the shortest path between Xen and York, we can use Dijkstra's algorithm. Here's the step-by-step reasoning:

1. **Initialize**:
   - Set the distance to the starting node (Eden) as 0.
   - Set the distance to all other nodes as infinity.
   - Create a priority queue to store nodes and their distances.

2. **Process Nodes**:
   - Extract the node with the smallest distance from the priority queue.
   - For each neighbor of the current node, calculate the tentative distance through the current node.
   - If this new distance is less than the current known distance, update the distance and add the neighbor to the priority queue.

3. **Continue until all nodes are processed**:
   - Continue this process until the priority queue is empty.

4. **Extract the shortest path**:
   - The distance from Eden to York will be the smallest distance found.

Let's implement this in Python:

```python
import heapq

# Nodes and edges
nodes = ['Amber', 'Bay', 'Blair', 'Eden', 'Glen', 'Kai', 'Oak', 'Tess', 'Xen', 'York']
distances = {node: float('inf') for node in nodes}

# Initialize distances
distances['Eden'] = 0

# Priority queue to store nodes and their distances
priority_queue = [(0, Eden)]

# Process nodes
while priority_queue:
    current_distance, current_node = heapq.heappop(priority_queue)
    
    # Update distances for neighbors
    for neighbor, weight in nodes[current_node].items():
        new_distance = current_distance + weight
        if new_distance < distances[neighbor]:
            distances[neighbor] = new_distance
            heapq.heappush(priority_queue, (new_distance, neighbor))

# Distance from Eden to York
distance_to_york = distances['Eden']

print(distance_to_york)
```
