We are given an undirected weighted graph with nodes:

**Nodes**: Drew, Hart, Kai, Nell, Quill, Sage, Vale, Xen  
**Edges and weights**:

- Drew–Hart: 2  
- Drew–Nell: 9  
- Drew–Quill: 1  
- Drew–Xen: 7  
- Hart–Kai: 8  
- Hart–Quill: 9  
- Hart–Vale: 9  
- Kai–Vale: 2  
- Nell–Vale: 8  
- Quill–Vale: 2  
- Sage–Vale: 5  
- Vale–Xen: 2  

We are to find the **shortest path from Hart to Vale**.

---

### Step 1: List all possible paths from Hart to Vale

We'll consider paths through various intermediate nodes.

#### Option 1: Direct edge  
Hart → Vale: **9**

#### Option 2: Hart → Kai → Vale  
Hart–Kai: 8, Kai–Vale: 2 → total = 8 + 2 = **10**

#### Option 3: Hart → Quill → Vale  
Hart–Quill: 9, Quill–Vale: 2 → total = 9 + 2 = **11**

#### Option 4: Hart → Drew → Quill → Vale  
Hart–Drew: 2, Drew–Quill: 1, Quill–Vale: 2 → total = 2 + 1 + 2 = **5**

Wait — is that valid?

Yes:  
Hart → Drew (2), Drew → Quill (1), Quill → Vale (2) → total = 5

That's better than direct (9).

#### Option 5: Hart → Drew → Xen → Vale

#### Option 6: Hart → Drew → Nell → Vale

#### Option 7: Hart → Drew → Quill → Sage → Vale?

Sage only connects to Vale (5). So:  
Hart → Drew → Quill → Sage → Vale:  
Drew–Quill: 1, Quill–Sage? No edge → invalid.

#### Option 8: Hart → Kai → Vale: already considered → 10

#### Option 9: Hart → Quill → Vale: 11

Is there any shorter?
