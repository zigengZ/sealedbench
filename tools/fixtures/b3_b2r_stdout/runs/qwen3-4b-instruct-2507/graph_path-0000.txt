- Amber–Drew: 2

- Kai–Quill: 3

- Poe–Vale: 5

We are to find the **shortest path from Jules to Poe**, and report the **total weight**.

---

### Step 1: Understand the connections

We need to go from **Jules** to **Poe**.

Jules is only connected to **Kai** (weight 2).

So any path from Jules to Poe must go through Kai.

So the path will be:  
**Jules → Kai → ??? → Poe**

We now need to find the shortest path from Kai to Poe.

Let’s consider all possible paths from Kai to Poe.

---

- Amber (1)

- Amber (1)
